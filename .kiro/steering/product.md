# プロダクト概要

勤怠管理SaaS。マルチテナント対応のWebアプリケーション。

## 主要機能

- 出退勤打刻（日跨ぎ勤務対応）
- 休憩管理
- 打刻修正・申請・承認フロー
- 休暇申請・承認
- 締め処理
- 勤怠一覧・集計

## マルチテナント

- 主要テーブルに `tenant_id` を持たせてデータ分離
- Firebase Auth の uid は業務モデルに直結させず、アプリ独自の user テーブルで管理

## 認可・ロール

- ADMIN / MANAGER / MEMBER
- 権限管理はアプリ側DBで制御（Firebase Auth は認証のみ）

## 日付・時刻方針

- DB保存: UTC
- 表示・業務ロジック: JST考慮
- 深夜時間、締め日、所定休日/法定休日を扱う

## 監査ログ

- 打刻修正、承認/差し戻し、締め処理の操作履歴を記録
